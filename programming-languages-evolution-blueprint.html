المحطة 00 // MACHINE ERA
العصر الآلي: حين كانت البرمجة حواراً مباشراً مع المعالج
The Machine Era: When Programming Was a Direct Conversation with the Processor
لا متغيرات بأسماء مفهومة، لا حلقات تكرار مريحة — فقط عناوين ذاكرة ومسجلات، وكل خطأ يعني إعادة كتابة كل شيء من الصفر تقريباً.
No variables with readable names, no convenient loops — just memory addresses and registers, and every error means rewriting almost everything from scratch.
أواخر 1940sLate 1940s
CORE LANGUAGES
لغة الآلة والأسمبلي
Machine Language & Assembly
أقرب لغة ممكنة للعتاد الفعلي؛ كل أمر يقابل تعليمة واحدة يفهمها المعالج مباشرة دون أي طبقة وسيطة.
The closest possible language to the actual hardware; every command maps to a single instruction the processor understands directly, with no intermediate layer.
IDE / VISUAL
بطاقات مثقّبة
Punch cards
لا محرر نصوص ولا بيئة تطوير؛ البرنامج فعلياً كومة من البطاقات الورقية المثقّبة تُغذّى للحاسوب يدوياً.
No text editor, no development environment; the program is literally a stack of punched paper cards fed to the computer by hand.
DATABASES
لا قواعد بيانات بعد
No databases yet
البيانات تُخزَّن على أشرطة مغناطيسية تُقرأ تسلسلياً من البداية للنهاية.
Data is stored on magnetic tapes read sequentially from start to end.
WEB & BIG DATA
لا وجود بعد
Doesn't exist yet
فكرة ربط الحواسيب ببعضها لم تولد بعد، فضلاً عن تحليل بيانات ضخمة.
The idea of linking computers together hasn't been born yet, let alone analyzing big data.
🎬 مشهد الإغلاق: مبرمج يراجع مئات البطاقات المثقّبة بحثاً عن خطأ واحد صغير — لا أحد يتخيل بعد أن جملة برمجية واحدة مقروءة ستكفي يوماً لفعل ما يحتاج اليوم مئة بطاقة.
🎬 Closing scene: a programmer reviews hundreds of punch cards hunting for one small error — no one imagines yet that a single readable line of code will one day suffice for what today needs a hundred cards.
المحطة 01 // HIGH-LEVEL BIRTH
ميلاد اللغات العليا: البرمجة تبدأ تشبه اللغة الإنسانية
The Birth of High-Level Languages: Programming Starts to Resemble Human Language
لأول مرة، يكتب المبرمج جملة تشبه الرياضيات أو الإنجليزية المبسّطة، والحاسوب هو من يتكفّل بترجمتها إلى لغة الآلة.
For the first time, a programmer writes a statement resembling math or simplified English, and the computer itself handles translating it into machine language.
1957 — 1964
CORE LANGUAGES
Fortran (1957) → Cobol (1959) → BASIC (1964)
فورتران للحوسبة العلمية والهندسية، كوبول لعالم الأعمال والمحاسبة، ثم بيسك لتبسيط تعلّم البرمجة للمبتدئين.
Fortran for scientific and engineering computing, Cobol for business and accounting, then BASIC to simplify programming for beginners.
IDE / VISUAL
مترجمات نصية فقط
Text compilers only
لا واجهات مرئية؛ البرمجة لا تزال سطر أوامر بحت، لكن الآن عبر لغة مقروءة لا رموزاً ثنائية.
No visual interfaces; programming is still pure command-line, but now through readable language, not binary symbols.
DATABASES
Flat Files
لا مفهوم SQL أو العلاقات بين الجداول بعد؛ كل تطبيق يدير ملفاته الخاصة بمنطقه الخاص.
No concept of SQL or table relationships yet; every application manages its own files with its own logic.
WEB & BIG DATA
لا وجود بعد
Doesn't exist yet
الحواسيب لا تزال معزولة تماماً كل عن الآخر.
Computers are still completely isolated from one another.
🎬 مشهد الإغلاق: طالب في الجامعة يكتب أول برنامج له بلغة BASIC خلال دقائق — شيء كان يستحيل تخيّله بلغة الآلة قبل سنوات قليلة فقط.
🎬 Closing scene: a university student writes their first BASIC program in minutes — something unimaginable in machine language just a few years earlier.
المحطة 02 // STRUCTURED ERA
البرمجة البنيوية وقواعد البيانات المكتبية
Structured Programming & Desktop Databases
الانضباط البرمجي يصبح قيمة بذاتها، وفي الوقت نفسه يظهر أول تطبيق يدمج "لغة برمجة" و"قاعدة بيانات" في منتج واحد يستخدمه غير المبرمجين.
Programming discipline becomes a value in itself, and at the same time, the first application merging a "programming language" and a "database" into one product used by non-programmers appears.
1970 — 1984
CORE LANGUAGES
Pascal (1970) · C (1972)
باسكال صُممت خصيصاً لتعليم البرمجة المنضبطة (Structured Programming)، بينما سي فتحت الباب لكتابة أنظمة تشغيل كاملة — بما فيها يونكس لاحقاً.
Pascal was designed specifically to teach structured programming, while C opened the door to writing complete operating systems — including Unix later on.
IDE / VISUAL
FoxBASE ثمFoxBASE, then FoxPro (1984)
أول موجة "برمجة + قاعدة بيانات" في تطبيق واحد على سطح المكتب — أصحاب المحال والمكاتب الصغيرة يديرون بياناتهم بأنفسهم دون مبرمج متخصص دائم.
The first wave of "programming + database" in a single desktop application — shop and small-office owners manage their own data without a permanent dedicated programmer.
DATABASES
FoxPro Databases (DBF)
صيغة تخزين محلية بسيطة، لكنها أول تجربة واسعة الانتشار لمفهوم "قاعدة بيانات" لدى غير المتخصصين.
A simple local storage format, but the first widely adopted experience of the "database" concept among non-specialists.
WEB & BIG DATA
لا وجود بعد
Doesn't exist yet
شبكات أكاديمية بحثية محدودة فقط (كأربانت)، لا مفهوم ويب عام بعد.
Only limited academic research networks (like ARPANET); no concept of a public web yet.
🎬 مشهد الإغلاق: صاحب متجر صغير يبني نظام مخزونه الخاص بلغة FoxPro دون أن يكون مبرمجاً محترفاً — بداية ديمقراطية البرمجة.
🎬 Closing scene: a small shop owner builds his own inventory system in FoxPro without being a professional programmer — the beginning of the democratization of programming.
المحطة 03 // VISUAL & .NET ERA
عصر البرمجة المرئية و.NET: الفأرة تشارك لوحة المفاتيح
The Visual & .NET Era: The Mouse Joins the Keyboard
بناء واجهة برنامج لم يعد يتطلب كتابة عشرات الأسطر لرسم زر واحد — يكفي سحبه وإفلاته، بينما يتكفّل الكود بنفسه خلف الكواليس.
Building an app interface no longer requires writing dozens of lines to draw a single button — just drag and drop it, while the code writes itself behind the scenes.
1991 — 2002
CORE LANGUAGES
Java (1995) كتقاطع تاريخي
Java (1995) as a historical crossing point
تظهر جافا بفلسفة مختلفة تماماً عن VB — "اكتب مرة، شغّل في أي مكان" — لتصبح لاحقاً لغة مؤسسات كبرى موازية لعالم مايكروسوفت المرئي.
Java appears with a philosophy completely different from VB — "write once, run anywhere" — later becoming a major enterprise language, running parallel to Microsoft's visual world.
IDE / VISUAL
Visual Basic (1991) → .NET Framework (2002)
VB يُدخل البرمجة المرئية بالسحب والإفلات؛ بعدها بعقد يُطلق .NET Framework ليوحّد لغتي C# وVB.NET تحت بيئة تطوير واحدة متكاملة لتطبيقات سطح المكتب.
VB introduces drag-and-drop visual programming; a decade later, .NET Framework launches, unifying C# and VB.NET under one integrated development environment for desktop applications.
DATABASES
توسع قواعد البيانات العلائقية المؤسسية
Enterprise relational databases expand
Oracle وSQL Server يكبران بالتوازي مع موجة سطح المكتب المرئي، خدمةً لتطبيقات الشركات الكبرى.
Oracle and SQL Server grow in parallel with the visual-desktop wave, serving large corporate applications.
WEB & BIG DATA
HTML يظهر (1991)
HTML appears (1991)
بتزامن لافت مع نفس عام Visual Basic — لكن هذا مسار مختلف تماماً سيتطور بمعزل عن سطح المكتب في الفصل القادم.
In a striking coincidence with the same year as Visual Basic — but this is a completely different track that will evolve apart from the desktop in the next chapter.
💡 نقطة تزامن مثيرة: عام 1991 شهد ولادة Visual Basic (سطح المكتب) وHTML (الويب) في نفس السنة تقريباً — طريقان متوازيان بدآ معاً، لكنهما سيتنافسان لاحقاً على مستقبل تطوير البرمجيات.
💡 An intriguing coincidence: 1991 saw the birth of both Visual Basic (desktop) and HTML (the web) in roughly the same year — two parallel paths that began together, but would later compete over the future of software development.
🎬 مشهد الإغلاق: مطوّر يبني نموذجاً أولياً كاملاً لتطبيق مبيعات خلال ساعة بدل أسبوع — البرمجة المرئية غيّرت سرعة التطوير جذرياً، لكنها لا تعلم بعد أن الويب سيسحب البساط تدريجياً خلال عقد.
🎬 Closing scene: a developer builds a complete sales-app prototype in an hour instead of a week — visual programming radically changed development speed, though it doesn't yet know the web will gradually pull the rug out from under it within a decade.
المحطة 04 // DATABASES & EARLY WEB
قواعد البيانات العلائقية والويب المبكر: البيانات تصبح "مهيكلة"
Relational Databases & the Early Web: Data Becomes "Structured"
للمرة الأولى، تُصبح البيانات نفسها موضوعاً له معاييره الخاصة — وتُصبح صفحات الويب أكثر من مجرد نصوص ثابتة.
For the first time, data itself becomes a subject with its own standards — and web pages become more than just static text.
1995 — 2000s
CORE LANGUAGES
نضوج C وJava
C and Java mature
تتحولان تدريجياً لتصبحا الأساس الخلفي (Backend) لأنظمة الويب والمؤسسات الكبرى.
They gradually become the backend foundation for web systems and large enterprises.
IDE / VISUAL
ذروة تطبيقات سطح المكتب
Desktop applications peak
Windows Forms وWPF يمثلان قمة نضج تطبيقات سطح المكتب المرئية، قبل أن يبدأ الاهتمام بالانتقال تدريجياً نحو الويب.
Windows Forms and WPF represent the peak maturity of visual desktop applications, before attention gradually begins shifting toward the web.
DATABASES
SQL معياراً موحّداً + MySQL (1995)
SQL as a unified standard + MySQL (1995)
MySQL مفتوحة المصدر تفتح الباب أمام مشاريع صغيرة ومتوسطة، ويترسّخ هنا مفهوم "البيانات المهيكلة" (Structured Data) كمعيار صناعي.
Open-source MySQL opens the door to small and medium projects, and the concept of "structured data" takes hold here as an industry standard.
WEB & BIG DATA
PHP (1995)
يضيف منطقاً برمجياً خلف صفحات HTML الثابتة — ميلاد الويب الديناميكي التفاعلي المرتبط مباشرة بقواعد البيانات مثل MySQL.
Adds programming logic behind static HTML pages — the birth of the dynamic, interactive web directly connected to databases like MySQL.
💡 نقطة تزامن مثيرة أخرى: عام 1995 وحده شهد ظهور Java وMySQL وPHP وJavaScript معاً — أربعة أعمدة ستشكّل لاحقاً معظم بنية الويب التحتية لعقدين قادمين، اثنان منها من جهة الخادم (PHP، MySQL) واثنان أقرب للواجهة والمنصة (Java، JavaScript).
💡 Another intriguing coincidence: 1995 alone saw the emergence of Java, MySQL, PHP, and JavaScript together — four pillars that would later form most of the web's infrastructure for the next two decades, two on the server side (PHP, MySQL) and two closer to the interface and platform layer (Java, JavaScript).
🎬 مشهد الإغلاق: أول موقع تجاري بسيط يعرض منتجاته من قاعدة بيانات MySQL عبر صفحات PHP — النموذج الذي سيهيمن على الويب لعقدين قادمين وُلد للتو.
🎬 Closing scene: the first simple commercial site displays its products from a MySQL database via PHP pages — the model that will dominate the web for the next two decades has just been born.
المحطة 05 // BIG DATA & MINING
عصر البيانات الضخمة والتنقيب: حين لا تكفي الجداول والأعمدة
The Big Data & Mining Era: When Rows and Columns Are No Longer Enough
السؤال لم يعد "كيف أخزّن البيانات؟" بل "كيف أفهم معنى مليارات السجلات التي لا تشبه بعضها بنية أو شكلاً؟"
The question is no longer "how do I store the data?" but "how do I make sense of billions of records that don't resemble each other in structure or form?"
2000s — 2026
CORE LANGUAGES
Python تتصدر المشهد
Python takes the lead
بفضل بساطتها وأطر عملها الغنية، تصبح اللغة الموحّدة تقريباً لعلم البيانات والذكاء الاصطناعي.
Thanks to its simplicity and rich frameworks, it becomes nearly the unified language for data science and artificial intelligence.
IDE / VISUAL
بيئات سحابية ودفاتر تفاعلية
Cloud environments & interactive notebooks
Jupyter وVS Code وبيئات التطوير السحابية تحل محل بيئات سطح المكتب التقليدية المثبّتة محلياً.
Jupyter, VS Code, and cloud development environments replace traditional locally-installed desktop environments.
DATABASES
البيانات غير المهيكلة تتصدر
Unstructured data takes the lead
نصوص، صور، فيديو، وسجلات استشعار لا تتوافق مع جداول SQL التقليدية — تظهر قواعد بيانات NoSQL ومستودعات بيانات ضخمة كاستجابة مباشرة.
Text, images, video, and sensor logs don't fit traditional SQL tables — NoSQL databases and massive data warehouses emerge as a direct response.
WEB & BIG DATA
Big Data + Data Mining
التنقيب في تدفقات البيانات الهائلة القادمة من الويب والتطبيقات والأجهزة الذكية يصبح تخصصاً قائماً بذاته لا مجرد استعلام SQL بسيط.
Mining the massive data streams flowing from the web, applications, and smart devices becomes an independent discipline, not just a simple SQL query.
🎬 مشهد الإغلاق: من بطاقة مثقّبة واحدة تحمل سطراً برمجياً واحداً، إلى نظام يُنقّب في مليارات السجلات غير المتجانسة كل ثانية — الرحلة نفسها أصبحت قصة عن تسارع الزمن لا مجرد تطور تقني.
🎬 Closing scene: from a single punch card carrying one line of code, to a system mining billions of heterogeneous records every second — this journey itself has become a story about the acceleration of time, not just technical evolution.
